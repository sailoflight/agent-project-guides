2026-10-24 的发布整理将本人路径、主机标识及私人分节示例泛化，并从共享历史移除 `.mnemon/` 私人运行归档。原始历史单独私有保留；第三方归属、许可、接口、失败结论、测量值和原始执行身份保持。

历史报告与项目记录中的绝对路径是泛化后的叙述。保留的 `project_digest`、历史提交引用和其他执行摘要仍标识原始执行输入，不能用当前派生副本重新计算后宣称复现了历史任务。旧 pilot 缺失、漂移以及已有验证范围的记录仍然有效，发布整理不构成真实外部 pilot、生产环境或客户端验收。

运行时的两个源文件仅替换整行注释中的人工分节示例，执行字节保持；安装测试中的两个允许通过的分节夹具改为通用示例。标记识别规则、角色、权限及加载语义保持。`PACKAGE_MANIFEST.json` 按各历史版本的实际派生文件重算字节数、SHA256 与规范化摘要，保持严格原生 schema；不往清单插入额外元数据。版本号保持，派生内容摘要发生变化，不能与原始包摘要混用。

两版历史架构视图分别经对应源码中的原生生成器重建并检查，仅源文件摘要和总证据摘要变化；模块、依赖、流程、源码锚点保持。该说明与架构导航均仅供源码维护，不进入通用运行时分发包或策略目录。

测试只在独立发布副本及临时 HOME/XDG 目录执行。已安装的精确固定包、实际项目检出、现有会话及全局记忆未迁移或改动。真实外部组件和旧 pilot 未运行时须如实保留 SKIP/GAP，不能把合成夹具通过解释为这些项目已验收。
